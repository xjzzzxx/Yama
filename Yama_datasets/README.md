# RQ1 datasets
This section contains two datasets:

- **`dataset1/`**: A general-purpose dataset compatible with most static analysis tools.
- **`dataset1_ForNAVEX_SQLI/`**: A specially crafted SQL Injection dataset designed to compensate for the limitations of the current `NAVEX_FIXED` version, which fails to detect XSS vulnerabilities.


# RQ2 datasets
The dataset for RQ2 is organized into three categories based on evaluation criteria:

- **`C1/`**: type_inference
- **`C2/`**: Dynamic_nature
- **`C3/`**: Buil-in_func
